给流水线用。调用 POST /api/shares/batch 时带上 Authorization: Bearer <token>， 上传的内容会记在当前账户的历史里。

怎么在 Gitea / GitHub Actions 里用 
curl -X POST https://bfs.example.com/api/shares/batch \
  -H "Authorization: Bearer $BFS_TOKEN" \
  -F "file=@firmware.bin" \
  -F "file=@symbols.zip"

响应里的 message 是可直接转发的文案，把 token 放进仓库 secret 即可。
